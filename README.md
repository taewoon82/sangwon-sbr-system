# sangwon-sbr-system

상원이엔씨 환경사업본부 SBR 설계검토·시스템 정립 원본 저장소.
**기준값과 도구의 원본은 여기 하나만 둔다.** 프로젝트·채팅에 올린 파일은 그 시점의 사본이다.

## 구성

| 폴더 | 내용 |
|---|---|
| `webapp/` | 물질수지·터빈 선정 웹앱 v12.1 (그림 글자 PDF 도면 글자 인식 · 압축파일 ZIP·RAR·7Z 자동 분류 · 도면 여러 장 합쳐 읽기 · 시방서 PDF 대조 · 첨부 상태 표시 · 도면 펌프·배관 표기 반영 · 용량계산서 엑셀 → 설계도면 DWG 대조 → 검토서 엑셀 출력 · 3D는 터빈 상세도면 반영 전까지 "업데이트 중"). `SBR_물질수지·터빈선정_v12.html` 을 크롬으로 열면 됨 |
| `desktop/` | 윈도우 데스크톱 앱 (Electron) — 웹앱과 같은 코드, 라이브러리 내장으로 인터넷 없이 동작. `./build_desktop.sh` 로 빌드, `make_update.py` 로 업데이트 파일(.zip) 생성 — 프로그램 메뉴 [업데이트]에서 적용 |
| `webapp/src/` | 웹앱 소스. `python build.py` 로 다시 만듦 (v8 본체 + v9 모듈 + 체크리스트 양식 내장) |
| `checklists/` | Project 체크리스트 정리본 (작성요령·검토서·기술제안서·설계·시공·시운전·변경내역) |
| `criteria/` | 기준값 단일 원본 — 터빈 카탈로그, 십자구조물 표준 치수, 검토서 판정 규칙 |
| `modeling-3d/` | 포기장치·배출장치·반응조 형상 사양(JSON)과 3D 모델 코드 (웹앱·유동해석 공용) |
| `cfd/` | 유동해석 (OpenFOAM v1912, simpleFoam + realizable k-ε) 케이스 생성·후처리·결과 뷰어 스크립트 |
| `sites/` | 현장별 메모 (확인된 값, 사용한 자료 목록). 원본 도면·계산서는 올리지 않음 |

## 업무 흐름

1. 용량계산서(엑셀) → 웹앱 Ⓟ: 물질수지·터빈 선정
2. 설계사 도면(DWG) → 웹앱 Ⓓ: 계산서·도면 대조표, 기둥·기기 위치, 3D
3. 웹앱 → 검토서 엑셀 출력 (체크리스트 양식 그대로, 판정 수식 유지)
4. 필요 시 유동해석: 형상 사양 + 카탈로그 조건 → `cfd/` → 결과 뷰어 HTML
5. 시공·시운전 체크리스트로 이어서 재검토

## 운영 규칙

- 기준값(카탈로그, 판정 기준, 표준 치수)은 `criteria/` 에서만 고친다.
- 파일을 고치면 커밋 메시지에 무엇을·왜 바꿨는지 한 줄로 적는다.
- 발주처·설계사 원본 자료(DWG, 계산서, 제작도 PDF)는 회사 드라이브에 둔다 (`.gitignore` 로 차단).
- 유동해석 계산 폴더는 용량이 커서 올리지 않는다. 케이스 조건(`cfd/cases/*.json`)과 결과 뷰어만 올린다.

## 유동해석 실행 (리눅스/WSL, OpenFOAM v1912)

```bash
cd cfd
./run2.sh 60 45          # cases/p60.json, p45.json → c60, c45 (격자·계산)
./cont.sh c60            # 3,000회까지 연장, 100회마다 저장 (평균용)
python3 cellgeom.py c60 2000
AVG=2000:3000 python3 post.py c60 post60.json
python3 assemble.py 결과.html
```

## 알려진 한계 (2026-10-23)

- 십자구조물 표준 치수는 1250형만 확인됨
