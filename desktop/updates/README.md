## 적용 방법
1. 위 표에서 가장 새 버전 파일 클릭 → 오른쪽 위 **Download raw file** (↓)
2. PC 프로그램 메뉴 **[업데이트] → [업데이트 파일 열기…]** → 받은 zip 선택 (압축 풀지 말고 그대로)
3. "새 버전 … 지금 업데이트" → 끝. 입력값은 그대로 남음. 문제가 있으면 **[처음 버전으로 되돌리기]**

## 처음 설치 (v12 미만 → v12)
업데이트 메뉴는 v12부터 있음. 설치 파일(`SBR-Design-Review_v12.0.0_win64.zip.zip`, 108MB — 받은 뒤 그대로 압축 해제)은
GitHub 파일 크기 제한(100MB) 때문에 저장소의 **Releases** 에 올려 둠.

## 새 업데이트 만들기 (개발용)
`desktop/make_update.py <버전> "변경 내용"` → 이 폴더에 넣고 위 표에 한 줄 추가
