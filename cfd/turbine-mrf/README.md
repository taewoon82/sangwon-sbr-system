# 터빈 실형상 회전 해석 (MRF) — 선회류 → 상향류 전환 신기술 검토

**상태: 1차 결과 (2026-10-27)** — 형상 검증 미완(동력 과대). 날개 단품 제작도 받으면 재보정.

## 목적
- 흡입 선회(pre-swirl)를 정지 고정날개로 제거했을 때 같은 rpm에서 토출량·축동력·동력당 토출량이 어떻게 변하는지 판정
- 2025 특허(10-2820906, 요철형 수평날개)의 "흡입부 회전 강화 → 상승류 강화" 논리와 반대 방향이라, 어느 쪽이 동력효율에 유리한지 해석으로 먼저 가림

- **정지형 흡입 선회 제거 날개는 어느 특허에도 없음.** 부유장치에 매달아 수위를 따라가는 구성이 후보.
- 카탈로그의 정류판·보정판·십자구조물은 간행물 공지라 그 자체로는 특허 신규성 없음.

## 모델
- 형상(`geom.py`): 카탈로그 1250형 치수 — 최대경 1,350, 흡입구 Ø832, 벨 높이 295, 채널 80, 날개 12매. 날개 감김각은 특허 도면 비율로 추정(기본 92°)하고 카탈로그 값으로 보정.
- 반응조: 장흥 기준 10.5×10.5×3.5 m, 45° 헌치 0.6 m, 십자구조물 2.5×0.2×1.2 m.
- 수면: 침수 +1(채널 상단 = 수면), 평평한 미끄럼면. 물보라·공기 혼입 없음 → 산소전달량은 안 나오고 토출량·동력 상대 비교용.
- 프로펠러(유량 약 1%)·기둥·플로트는 제외.
- 해석: OpenFOAM v1912 simpleFoam + MRF, k-ω SST, 약 36만 셀.

## 검증 기준 (카탈로그)
- 선속도 5.5 m/s = Ø1,350 기준 77.8 rpm
- 토출량 2,100 m³/h, 동력 8.8(침수 −1) ~ 12.5 kW(침수 +1)

## 실행
```bash
python3 geom.py g0 92 0        # 형상 (감김각, 정지날개 0/1)
python3 mkcase.py c0 g0 77.8 0 # 케이스 (rpm, 정지날개)
./mesh.sh c0 && ./run.sh c0
python3 post.py c0 77.8        # 흡입·토출 유량, 흡입 선회비, 축동력
```
참고: Ubuntu 24.04 패키지판 v1912는 함수객체(forces 등)가 `sha1` 오류로 실패해서, 토크는 `post.py`가 메시를 직접 읽어 압력·벽전단으로 계산함.

## 1차 결과 (2026-10-27)

### 검증 (77.8 rpm, 침수 +1) — 미통과
| 항목 | 해석 | 카탈로그 |
|---|---|---|
| 흡입 유량 | 약 2,890 m³/h | 토출 2,100 / 순환 2,800 |
| 축동력 | 약 22.9 kW | 12.5 kW |
- 동력이 약 1.8배 큼. 그림 비율로 추정한 날개(출구 반경방향, 덮개 폭)가 실제보다 공격적인 것으로 봄. 각도를 임의 조정해 맞추지 않음 → 날개 단품 제작도 필요.
- 69.6 rpm과 비교하면 유량 ∝ rpm, 동력 ∝ rpm³ 상사법칙은 맞음(내부 일관성 확인).

### 정지 고정날개 비교 (69.6 rpm, 마지막 1,000회 3시점 평균)
| 케이스 | 흡입 유량 | 축동력 | 동력당 유량 | 흡입 선회/날개속도 |
|---|---|---|---|---|
| 기본 | 2,570 m³/h (2,500~2,635) | 16.3 kW (15.7~16.7) | 158 m³/h/kW | +0.03~+0.09 |
| 고정날개 8매 | 2,745 m³/h (2,733~2,757) | 17.0 kW (16.9~17.2) | 162 m³/h/kW | −0.05~−0.08 |
- 동력당 유량 +2.5%로, 기본 케이스 자체의 흔들림(±3%) 안이라 **효과를 구분할 수 없음**.
- 이유: 사각조 + 십자구조물 + 헌치에서 **터빈 흡입구로 들어오는 물의 선회가 이미 날개속도의 2~9%뿐**. 고정날개가 없앨 선회가 없음.
- 반응조 선회 분포(`swirlmap.py`): 양(+)의 선회는 수면 터빈 주변(반경 1.5 m 이내)에만 있고, 중간 깊이 바깥쪽은 오히려 역회전(−0.1~−0.2 m/s).

### 판단
- 이 조건(사각조, 십자구조물 있음)에서는 "흡입 선회 제거 → 상승 유량 증가" 기술은 효과가 작아 신기술 근거로 약함.
- 효과가 나올 수 있는 조건: 원형조, 십자구조물이 없거나 작은 반응조, S:T가 큰 얕은 조 — 선회가 실제로 큰 경우. 해석 전에 현장에서 벽 근처 중간 깊이 접선유속을 실측해 선회가 실제로 있는지 먼저 확인하는 게 맞음.
- 한계: 형상 미검증, 정상상태 MRF(동결 회전자), 평평한 수면.
