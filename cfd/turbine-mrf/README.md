# 터빈 실형상 회전 해석 (MRF) — 선회류 → 상향류 전환 신기술 검토

**상태: 진행 중 (2026-10-26)** — 1250형 검증 케이스 계산 중. 결과는 확인 후 이 문서에 추가.

## 목적
- 흡입 선회(pre-swirl)를 정지 고정날개로 제거했을 때 같은 rpm에서 토출량·축동력·동력당 토출량이 어떻게 변하는지 판정
- 2025 특허(10-2820906, 요철형 수평날개)의 "흡입부 회전 강화 → 상승류 강화" 논리와 반대 방향이라, 어느 쪽이 동력효율에 유리한지 해석으로 먼저 가림

## 특허 검토 요약 (자사 등록특허 5건)

- **정지형 흡입 선회 제거 날개는 어느 특허에도 없음.** 부유장치에 매달아 수위를 따라가는 구성이 후보.
- 카탈로그의 정류판·보정판·십자구조물은 간행물 공지라 그 자체로는 특허 신규성 없음.

## 모델
- 형상(`geom.py`): 카탈로그 1250형 치수 — 최대경 1,350, 흡입구 Ø832, 벨 높이 295, 채널 80, 날개 12매. 날개 감김각은 특허 도면 비율로 추정(기본 92°)하고 카탈로그 값으로 보정.
- 반응조: 장흥 기준 10.5×10.5×3.5 m, 45° 헌치 0.6 m, 십자구조물 2.5×0.2×1.2 m.
- 수면: 침수 +1(채널 상단 = 수면), 평평한 미끄럼면. 물보라·공기 혼입 없음 → 산소전달량은 안 나오고 토출량·동력 상대 비교용.
- 프로펠러(유량 약 1%)·기둥·플로트는 제외.
- 해석: OpenFOAM v1912 simpleFoam + MRF, k-ω SST, 약 36만 셀.

## 검증 기준 (카탈로그)
- 선속도 5.5 m/s = Ø1,350 기준 77.8 rpm
- 토출량 2,100 m³/h, 동력 8.8(침수 −1) ~ 12.5 kW(침수 +1)

## 실행
```bash
python3 geom.py g0 92 0        # 형상 (감김각, 정지날개 0/1)
python3 mkcase.py c0 g0 77.8 0 # 케이스 (rpm, 정지날개)
./mesh.sh c0 && ./run.sh c0
python3 post.py c0 77.8        # 흡입·토출 유량, 흡입 선회비, 축동력
```
참고: Ubuntu 24.04 패키지판 v1912는 함수객체(forces 등)가 `sha1` 오류로 실패해서, 토크는 `post.py`가 메시를 직접 읽어 압력·벽전단으로 계산함.
